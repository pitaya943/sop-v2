# Template-owned paths (design doc 11, 14.5). sop-sync overwrites them; projects
# must not edit them (CI readonly-paths). Project-owned files are never listed here.
#
# Format: <path>  [module:<name>]
#   - One path per line, relative to the repo root. A trailing "/" marks a directory.
#   - A path without a module tag is core and always synced.
#   - "module:<name>" ties the path to the optional module modules.<name> in
#     .sop/config.yml; bootstrap deletes it and sop-sync skips it while the module is off.
#
# Some paths are created in later stages (S1-S3); listing them now fixes ownership early.
