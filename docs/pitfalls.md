# 踩過的坑 / Pitfalls

只收「下一個 agent 不知道就會再犯」的事。由 Chief 在 milestone 結束時整理；Builder 與 Verifier 只能在 PR 說明裡提議。上限 30 條；超過時先刪掉已經被 CI 檢查或 skill 取代的條目。刪除的條目不重新編號。

> **EN:** Only things the next agent would repeat without knowing. Curated by the Chief at milestone end; Builders and Verifiers only propose in PR descriptions. At most 30 entries; remove ones superseded by a CI check or skill first. Deleted entries are never renumbered.
